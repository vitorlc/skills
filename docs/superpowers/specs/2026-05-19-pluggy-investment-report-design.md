# Design: Skill `pluggy-investment-report`

**Date:** 2026-05-19  
**Status:** Approved

---

## Summary

A Claude Code skill that fetches consolidated investment data from the Pluggy API and produces:
1. A Markdown summary displayed in the terminal
2. A rich HTML dashboard (`relatorio.html`) generated by a bundled Python script, with charts and PDF export support

---

## File Structure

```
~/.claude/skills/pluggy-investment-report/
├── SKILL.md
├── scripts/
│   └── generate_report.py
└── references/
    └── pluggy-api.md
```

---

## Architecture

### Execution Flow

1. User invokes the skill (e.g., `/pluggy-investment-report`)
2. Claude reads `references/pluggy-api.md` for endpoint documentation
3. Claude asks the user for their Pluggy **Client ID** and **Client Secret** (or reads from env vars `PLUGGY_CLIENT_ID` / `PLUGGY_CLIENT_SECRET`)
4. Claude authenticates: `POST /auth` → receives `apiKey`
5. Claude fetches all connected accounts: `GET /items` → list of `itemId`s
6. For each `itemId`, Claude fetches: `GET /investments?itemId={id}` → consolidates into a single list
7. Claude displays a **Markdown summary** in the terminal:
   - Total amount invested
   - Total gross return (R$) and percentage
   - Breakdown by asset type (Renda Fixa, Ações, Fundos, etc.)
8. Claude writes consolidated data to a temp JSON file
9. Claude runs `generate_report.py` passing the temp JSON path
10. Script generates `relatorio.html` in the current working directory
11. Claude opens `relatorio.html` in the default browser

## Components

### `SKILL.md`

Instructions for Claude covering:
- **Setup section:** How to sign up at Pluggy sandbox (pluggy.ai), create an app, and obtain Client ID + Client Secret
- **Authentication:** Step-by-step API call sequence with exact endpoints and payloads
- **Data fetching:** How to paginate items and investments if needed
- **Markdown summary format:** Exact template Claude must follow for terminal output
- **Script invocation:** How to call `generate_report.py` with the data file path
- **Error handling:** What to do if auth fails, no investments found, or script errors

### `scripts/generate_report.py`

Standalone Python script (stdlib only, pure string formatting — no pip installs required):
- Reads consolidated investment JSON from a file path passed as argument
- Produces a single self-contained `relatorio.html` file
- **HTML contents:**
  - Header with generation date and total portfolio value
  - 3 summary cards: Total Investido, Rendimento Total (R$), Retorno (%)
  - Pie chart (Chart.js via CDN): allocation by asset type
  - Bar chart (Chart.js via CDN): value by institution
  - Sortable table: each asset with columns — Name, Institution, Type, Invested Amount, Current Value, Return (R$), Return (%), Maturity Date
  - Print/PDF button with `@media print` CSS (hides button, formats for A4)

**Dependencies:** Python 3.8+, no pip installs required (Chart.js loaded via CDN)

### `references/pluggy-api.md`

Compact API reference with:
- Base URL: `https://api.pluggy.ai`
- `POST /auth` — request/response example
- `GET /items` — response structure
- `GET /investments?itemId={id}` — response structure with investment fields
- Field mapping: which API fields map to report columns
- Sandbox note: how to create test items in sandbox environment

## Error Handling

| Scenario | Claude's behavior |
|---|---|
| Missing credentials | Ask user to provide Client ID / Secret or set env vars |
| Auth failure (401) | Show error message, remind user to check credentials |
| No items connected | Inform user and link to Pluggy dashboard to connect accounts |
| No investments found | Show message, still generate empty-state HTML |
| Python not available | Inform user, offer to print raw data as Markdown table instead |
| `relatorio.html` already exists | Overwrite without prompting (always fresh data) |

---

## Success Criteria

- Claude successfully authenticates and fetches real (or sandbox) investment data
- Terminal shows a readable Markdown summary with totals and breakdown
- `relatorio.html` opens in browser showing charts and full asset table
- HTML prints cleanly to PDF via browser print dialog
- Skill works end-to-end from zero (includes setup instructions for new Pluggy users)
